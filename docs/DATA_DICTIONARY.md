# พจนานุกรมข้อมูล (Data Dictionary)

## 1. ข้อมูลชุดข้อมูล (Dataset Overview)
- **ชื่อชุดข้อมูล:** การประชุมคณะกรรมการสิ่งแวดล้อมแห่งชาติ
- **หน่วยงานเจ้าของข้อมูล:** สำนักงานนโยบายและแผนทรัพยากรธรรมชาติและสิ่งแวดล้อม (สผ.) กระทรวงทรัพยากรธรรมชาติและสิ่งแวดล้อม
- **แหล่งที่มา:** Open Government Data of Thailand (data.go.th)
- **URL ชุดข้อมูล:** https://data.go.th/dataset/10083-11
- **รูปแบบไฟล์ต้นฉบับ:** CSV (Encoding: `utf-8-sig`)
- **ช่วงข้อมูล:** ปีงบประมาณ พ.ศ. 2561 - 2567 (รวม 523 รายการวาระ)
- **ไฟล์ในระบบ:**
  - `data/raw/neb_board_meeting.csv`: ข้อมูลดิบจาก สผ.
  - `data/processed/neb_meeting_processed.csv`: ข้อมูลที่ผ่านการทำความสะอาดและจัดเรียงแล้ว

## 2. คำอธิบายคอลัมน์ (Column Definitions)

| ชื่อคอลัมน์ | ชนิดข้อมูล | ตัวอย่างค่า | คำอธิบาย |
| :--- | :--- | :--- | :--- |
| `ปีงบประมาณ พ.ศ.` | Integer | `2567`, `2566` | ปีงบประมาณของการประชุม |
| `ครั้งที่` | String / Int | `1`, `2`, `4` | ครั้งที่ของการประชุมในปีนั้น ๆ |
| `วันที่` | String | `30 พฤศจิกายน 2017` | วัน เดือน ปีที่จัดการประชุม |
| `เดือน` | String | `พฤศจิกายน`, `มีนาคม` | เดือนภาษาไทยที่สกัดจากวันที่ (ใช้เรียงลำดับปฏิทิน) |
| `เวลา` | String | `9:30 น.` | เวลาเริ่มการประชุม |
| `รูปแบบการประชุม` | String | `on site`, `online` | ช่องทางการจัดประชุม (ณ สถานที่ หรือผ่านระบบออนไลน์) |
| `ห้องประชุม` | String | `401`, `301` | ห้องประชุม |
| `สถานที่` | String | `สำนักงานนโยบายและแผน...` | สถานที่จัดประชุม |
| `ประเภทวาระ` | String | `เรื่องเพื่อพิจารณา`, `เรื่องเพื่อทราบ` | ประเภทของวาระการประชุม |
| `วาระที่` | String | `3.1`, `3.3` | หมายเลขลำดับวาระ |
| `ชื่อวาระ` | String | รายละเอียดวาระ | หัวข้อและชื่อเรื่องของวาระการประชุม |
| `ประเภทเรื่อง` | String | `การพิจารณาโครงการ`, `นโยบาย/แผน` | หมวดหมู่ประเภทของเรื่องที่นำเสนอ |
| `ด้าน` | String | `ด้านนโยบายและการบริหาร`, `ด้าน EIA` | ด้านสิ่งแวดล้อมที่เกี่ยวข้อง |
| `เจ้าของวาระ` | String | `สผ.`, `กรมควบคุมมลพิษ` | หน่วยงานหลักที่เสนอวาระเข้าที่ประชุม |
| `เจ้าของโครงการ` | String | บริษัท / หน่วยงาน | เจ้าของโครงการที่นำเสนอรายงาน (ถ้ามี) |
