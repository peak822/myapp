# พจนานุกรมข้อมูล (Data Dictionary)

## 1. ข้อมูลชุดข้อมูล (Dataset Overview)
- **ชื่อชุดข้อมูล:** ปริมาณขยะมูลฝอย ภายในหน่วยงาน
- **หน่วยงานเจ้าของข้อมูล:** กรมอุทยานแห่งชาติ สัตว์ป่า และพันธุ์พืช กระทรวงทรัพยากรธรรมชาติและสิ่งแวดล้อม
- **แหล่งที่มา:** Open Government Data of Thailand (data.go.th)
- **URL ชุดข้อมูล:** https://data.go.th/dataset/gdpublish-69-dnp01-11-01
- **รูปแบบไฟล์ต้นฉบับ:** CSV (Encoding: `cp874` / `tis-620`)
- **ไฟล์ที่จัดเก็บในระบบ:**
  - `data/raw/waste_2568.csv`: สถิติข้อมูลประจำปีงบประมาณ 2568
  - `data/raw/waste_2569.csv`: สถิติข้อมูลประจำปีงบประมาณ 2569
  - `data/processed/waste_data_combined.csv`: ข้อมูลที่ผ่านการรวมและทำความสะอาดแล้ว (Encoding: `utf-8-sig`)

## 2. คำอธิบายคอลัมน์ (Column Definitions)

| ชื่อคอลัมน์ (ภาษาไทย) | ชื่อคอลัมน์มาตรฐาน | ชนิดข้อมูล | หน่วยวัด | คำอธิบายและความหมาย |
| :--- | :--- | :--- | :--- | :--- |
| `ปี` | `year` | Integer | ปี พ.ศ. | ปีงบประมาณของข้อมูล (เช่น 2568, 2569) |
| `สังกัด` | `affiliation` | String | - | การแบ่งกลุ่มหน่วยงาน เช่น `ส่วนกลาง`, `ส่วนภูมิภาค` |
| `หน่วยงาน` | `department` | String | - | ชื่อเต็มของสำนัก กอง หรือหน่วยงานย่อย |
| `เดือน` | `month` | String | - | ชื่อเดือนภาษาไทย (มกราคม - ธันวาคม) |
| `คนเฉลี่ย` | `avg_staff` | Float / Int | คน | จำนวนบุคลากรเฉลี่ยต่อเดือนในหน่วยงานนั้น |
| `วันทำงาน` | `work_days` | Float / Int | วัน | จำนวนวันทำงานในเดือนนั้น |
| `โฟมบรรจุอาหาร (ใบ)` | `foam_containers` | Float / Int | ใบ | ปริมาณโฟมบรรจุอาหารที่ใช้/ทิ้ง (มักเป็น 0 ตามนโยบายงดใช้โฟม) |
| `ขยะที่เกิดขึ้น (กก.)` | `waste_generated_kg` | Float | กิโลกรัม (กก.) | ปริมาณขยะที่เกิดขึ้นทั้งหมดภายในหน่วยงาน |
| `นำไปใช้ประโยชน์ (กก.)` | `waste_recycled_kg` | Float | กิโลกรัม (กก.) | ปริมาณขยะที่นำกลับไปรีไซเคิลหรือใช้ประโยชน์ |
| `ขยะที่ส่งกำจัด (กก.)` | `waste_disposed_kg` | Float | กิโลกรัม (กก.) | ปริมาณขยะที่ไม่สามารถนำไปใช้ประโยชน์และต้องส่งไปกำจัด |
| `ร้อยละขยะส่งกำจัดลดลง` | `disposal_reduction_pct`| Float | เปอร์เซ็นต์ (%) | ร้อยละของการลดปริมาณขยะที่ส่งกำจัดเทียบกับเกณฑ์ |

## 3. กฎการทำความสะอาดและแปลงข้อมูล (Cleaning & Standardization Rules)
1. **การอ่านไฟล์ (File Encoding):**
   - ไฟล์ดิบใช้การเข้ารหัสแบบ `cp874` ต้องระบุ encoding อย่างถูกต้องเพื่อป้องกันตัวอักษรอ่านไม่ออก (Mojibake)
2. **การปรับชื่อคอลัมน์ให้ตรงกัน (Column Harmonization):**
   - ปี 2568 มีคอลัมน์ `ใช้ประโยชน์ (กก.)` -> ปรับเป็น `นำไปใช้ประโยชน์ (กก.)`
   - ปี 2568 มีคอลัมน์ `ร้อยละส่งกำจัดลดลง` -> ปรับเป็น `ร้อยละขยะส่งกำจัดลดลง`
3. **การแปลงชนิดข้อมูลตัวเลข:**
   - คอลัมน์ `คนเฉลี่ย`, `วันทำงาน`, `โฟมบรรจุอาหาร (ใบ)`, `ขยะที่เกิดขึ้น (กก.)`, `นำไปใช้ประโยชน์ (กก.)`, `ขยะที่ส่งกำจัด (กก.)`, `ร้อยละขยะส่งกำจัดลดลง` แปลงเป็นตัวเลข (numeric) โดยแทนที่ค่าว่างหรือผิดรูปแบบด้วย 0 หรือค่ามัธยฐานตามความเหมาะสม
4. **ลำดับเดือน (Month Sorting):**
   - กำหนดลำดับเดือนตามปฏิทินไทย: `['มกราคม', 'กุมภาพันธ์', 'มีนาคม', 'เมษายน', 'พฤษภาคม', 'มิถุนายน', 'กรกฎาคม', 'สิงหาคม', 'กันยายน', 'ตุลาคม', 'พฤศจิกายน', 'ธันวาคม']` เพื่อให้กราฟรายเดือนเรียงลำดับได้อย่างถูกต้อง
