# 🌿 National Environmental Board Meeting Dashboard (Streamlit)

เว็บแอปพลิเคชันสำหรับวิเคราะห์และแสดงผลข้อมูล **การประชุมคณะกรรมการสิ่งแวดล้อมแห่งชาติ** (ปีงบประมาณ พ.ศ. 2561 - 2567) พัฒนาด้วย **Python**, **Pandas**, **Streamlit** และสร้างการแสดงผลเชิงโต้ตอบด้วย **Plotly**

---

## 📌 แหล่งข้อมูล (Data Sources)
- **Dataset:** [การประชุมคณะกรรมการสิ่งแวดล้อมแห่งชาติ - Open Government Data of Thailand (data.go.th)](https://data.go.th/dataset/10083-11)
- **หน่วยงานเจ้าของข้อมูล:** สำนักงานนโยบายและแผนทรัพยากรธรรมชาติและสิ่งแวดล้อม (สผ.) กระทรวงทรัพยากรธรรมชาติและสิ่งแวดล้อม

---

## ✨ ฟีเจอร์หลัก (Features)

1. **ตัวกรองข้อมูลเชิงโต้ตอบ (Interactive Filters):**
   - กรองตาม **ปีงบประมาณ พ.ศ.** (2561 - 2567)
   - กรองตาม **ประเภทวาระ** (เรื่องเพื่อพิจารณา, เรื่องเพื่อทราบ)
   - กรองตาม **ด้านสิ่งแวดล้อม** (ด้านนโยบายและการบริหาร, ด้านการประเมินผลกระทบสิ่งแวดล้อม, ด้านมาตรฐานคุณภาพสิ่งแวดล้อม ฯลฯ)
   - กรองตาม **รูปแบบการประชุม** (on site, online)
   - กรองตาม **เดือน** (มกราคม - ธันวาคม)
2. **สรุปภาพรวมตัวชี้วัด (KPI Metrics Cards):**
   - วาระการประชุมทั้งหมด (วาระ)
   - จำนวนเรื่องเพื่อพิจารณา (วาระ)
   - จำนวนเรื่องเพื่อทราบ (วาระ)
   - จำนวนการประชุมรูปแบบ On-site (วาระ)
   - จำนวนการประชุมรูปแบบ Online (วาระ)
3. **การแสดงผลกราฟิก (Data Visualizations - 6 กราฟ):**
   - 📈 **Stacked Bar Chart:** แนวโน้มจำนวนวาระการประชุมตามปีงบประมาณ จำแนกตามประเภทวาระ
   - 🍩 **Donut Chart:** สัดส่วนประเภทเรื่องการประชุม (พิจารณาโครงการ, นโยบาย/แผน, ผลการดำเนินงาน ฯลฯ)
   - 📊 **Horizontal Bar Chart:** การจำแนกวาระตามด้านสิ่งแวดล้อม
   - 💻 **Grouped Bar Chart:** เปรียบเทียบรูปแบบการประชุม (On-site vs Online) แต่ละปีงบประมาณ
   - 🏛️ **Horizontal Bar Chart:** หน่วยงานเจ้าของวาระสูงสุด
   - 📅 **Bar Chart:** จำนวนวาระการประชุมจำแนกตามเดือนในรอบปี
4. **ตารางรายละเอียดข้อมูล (Data Table):**
   - แสดงรายละเอียดวาระ ชื่อวาระ วาระที่ วันที่ สถานที่ พร้อมระบบค้นหา จัดเรียง และกรองข้อมูลแบบ Dynamic

## 🚀 การติดตั้งและรันโปรเจกต์ในเครื่อง (Local Setup)

### 1. ติดตั้ง Dependencies
```bash
pip install -r requirements.txt
```

### 2. รันแอปพลิเคชัน Streamlit
```bash
streamlit run app.py
```
เปิดใช้งานผ่านเบราว์เซอร์ที่ `http://localhost:8501`
